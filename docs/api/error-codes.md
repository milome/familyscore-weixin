# 错误码说明

## 错误码分类

| 范围 | 类别 |
|------|------|
| 0 | 成功 |
| 1000-1999 | 通用错误 |
| 2000-2999 | 认证相关 |
| 3000-3999 | 家庭相关 |
| 4000-4999 | 成员相关 |
| 5000-5999 | 规则相关 |
| 6000-6999 | 记录相关 |
| 7000-7999 | 刮刮卡相关 |
| 8000-8999 | 系统错误 |

## 详细错误码

### 通用错误 (1000-1999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 0 | 成功 | - |
| 1001 | 参数错误 | 检查请求参数是否符合要求 |
| 1002 | 未授权 | 请先登录 |
| 1003 | 权限不足 | 需要更高权限的角色 |
| 1004 | 资源不存在 | 检查资源 ID 是否正确 |
| 1005 | 操作失败 | 请稍后重试 |
| 1006 | 请求过于频繁 | 降低请求频率 |
| 1007 | 数据验证失败 | 检查数据格式 |
| 1008 | 数据库错误 | 请联系管理员 |

### 认证相关 (2000-2999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 2001 | 登录凭证无效 | 重新调用 wx.login |
| 2002 | 登录已过期 | 重新登录 |
| 2003 | Token 无效 | 清除缓存重新登录 |
| 2004 | 获取用户信息失败 | 检查用户授权 |

### 家庭相关 (3000-3999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 3001 | 邀请码无效 | 检查邀请码是否正确 |
| 3002 | 邀请码已过期 | 请重新生成邀请码 |
| 3003 | 家庭已满员 | 家庭成员数量已达上限 |
| 3004 | 用户已在家庭中 | 无需重复加入 |
| 3005 | 家庭不存在 | 检查家庭 ID |
| 3006 | 不能退出自己创建的家庭 | 需要转让或解散家庭 |

### 成员相关 (4000-4999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 4001 | 成员不存在 | 检查成员 ID |
| 4002 | 不能删除自己 | 请使用退出家庭功能 |
| 4003 | 成员名称重复 | 使用其他名称 |
| 4004 | 积分不足 | 积分不能为负数 |

### 规则相关 (5000-5999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 5001 | 规则不存在 | 检查规则 ID |
| 5002 | 规则名称重复 | 使用其他名称 |
| 5003 | 积分值无效 | 检查积分值范围 |

### 记录相关 (6000-6999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 6001 | 记录不存在 | 检查记录 ID |
| 6002 | 不能修改已确认的记录 | 记录已锁定 |

### 刮刮卡相关 (7000-7999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 7001 | 刮刮卡不存在 | 检查卡片 ID |
| 7002 | 刮刮卡已使用 | 不能重复刮开 |
| 7003 | 刮刮卡已过期 | 卡片已过期 |
| 7004 | 奖励已领取 | 不能重复领取 |

### 系统错误 (8000-8999)

| 错误码 | 说明 | 解决方案 |
|--------|------|----------|
| 8001 | 服务器内部错误 | 请联系管理员 |
| 8002 | 服务暂时不可用 | 请稍后重试 |
| 8003 | 第三方服务错误 | 依赖服务异常 |

## 错误处理示例

```javascript
// 统一错误处理
const handleApiError = (error) => {
  const errorCode = error.code || 8001
  const errorMessage = error.message || '未知错误'

  switch (errorCode) {
    case 1002:
    case 2002:
      // 需要重新登录
      wx.redirectTo({ url: '/pages/login/index' })
      break
    case 1003:
      // 权限不足
      wx.showToast({
        title: '权限不足',
        icon: 'none'
      })
      break
    case 1006:
      // 请求过于频繁
      wx.showToast({
        title: '操作太频繁，请稍后再试',
        icon: 'none'
      })
      break
    default:
      wx.showToast({
        title: errorMessage,
        icon: 'none'
      })
  }
}

// 使用示例
wx.cloud.callFunction({
  name: 'someFunction',
  data: params
}).catch(handleApiError)
```
