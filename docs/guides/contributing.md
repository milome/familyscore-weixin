# 贡献指南

感谢您对家庭积分管理小程序的兴趣！我们欢迎各种形式的贡献。

## 如何贡献

### 报告问题

如果您发现了 bug 或有功能建议：

1. 先搜索是否已有相关 issue
2. 如果没有，创建新的 issue
3. 使用对应的模板填写信息
4. 提供详细的复现步骤（如果是 bug）

### 提交代码

#### 开发流程

1. **Fork 仓库**
   ```bash
   git clone https://github.com/your-username/FAMILYSCORE-WEXIN.git
   cd FAMILYSCORE-WEXIN
   ```

2. **创建分支**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **提交更改**
   ```bash
   git add .
   git commit -m "feat: 添加新功能"
   ```

4. **推送分支**
   ```bash
   git push origin feature/your-feature-name
   ```

5. **创建 Pull Request**

#### 提交信息规范

提交信息格式：

```
<type>: <subject>

<body>

<footer>
```

类型说明：
- `feat`: 新功能
- `fix`: 修复
- `docs`: 文档
- `style`: 格式（不影响代码运行的变动）
- `refactor`: 重构
- `perf`: 性能优化
- `test`: 测试
- `chore`: 构建过程或辅助工具的变动

示例：
```
feat: 添加积分记录导出功能

- 支持导出为 Excel 格式
- 添加导出进度提示
- 优化大数据量导出性能

Closes #123
```

### 代码规范

#### JavaScript

- 使用 ES6+ 语法
- 使用单引号
- 语句末尾使用分号
- 2 个空格缩进
- 最大行长度 100 字符

#### 样式

- 使用 BEM 命名规范
- 避免使用 `!important`
- 优先使用 CSS 变量

#### 组件

- 组件名使用 kebab-case
- 属性名使用 camelCase
- 必须包含完整的四个文件（js/json/wxml/wxss）

### 测试

提交前请确保：

- [ ] 代码可以正常编译
- [ ] 功能在开发者工具中测试通过
- [ ] 真机测试通过
- [ ] 没有引入新的 lint 错误

### 文档更新

如果更改影响了用户界面或 API，请同步更新相关文档：

- `docs/api/` - API 文档
- `docs/components.md` - 组件文档
- `docs/guides/` - 使用指南
- `docs/changelog.md` - 更新日志

## 开发环境

### 环境要求

- Node.js >= 14.0.0
- 微信开发者工具 >= 1.06.2307260

### 安装依赖

```bash
npm install
```

### 启动开发

1. 打开微信开发者工具
2. 导入项目
3. 开启云开发

## 代码审查

所有提交都需要经过代码审查：

1. 至少一名维护者审查通过
2. 所有 CI 检查通过
3. 没有冲突需要解决

## 行为准则

### 我们的承诺

为了营造一个开放和友好的环境，我们作为贡献者和维护者承诺：

- 尊重不同的观点和经验
- 接受建设性的批评
- 关注对社区最有利的事情
- 对其他社区成员表示同理心

### 我们的标准

有助于创造积极环境的行为：

- 使用友好和包容的语言
- 尊重不同的观点和经验
- 优雅地接受建设性批评
- 关注对社区最有利的事情
- 对其他社区成员表示同理心

不可接受的行为：

- 使用带有性暗示的语言或图像
- 进行挑衅、侮辱/贬低性的评论，以及个人或政治攻击
- 公开或私下的骚扰
- 未经明确许可，发布他人的私人信息
- 其他不道德或不专业的行为
