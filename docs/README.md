## 项目简介

家庭积分管理小程序是一个帮助家庭成员管理日常积分的小程序应用，支持：

- 家庭成员管理（家长、孩子）
- 积分规则自定义
- 积分记录追踪
- 数据统计分析
- 刮刮卡奖励系统

## 技术栈

- **前端**: 微信小程序原生开发
- **后端**: 微信云开发（云数据库 + 云函数 + 云存储）
- **开发工具**: 微信开发者工具
